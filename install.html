홈 화면에 추가하면 앱처럼 바로 열고
인증·응원 알림도 놓치지 않아요

안에서는 설치할 수 없어요.
아래 버튼으로 인터넷 앱()에서 다시 열어주세요.
아이폰은 Safari에서만 설치할 수 있어요.
Safari를 열고 이 주소를 붙여넣어 주세요.

아이폰 · 3단계

1
Safari 하단의 공유 버튼 ⬆️을 눌러요
2
메뉴를 아래로 내려서 "홈 화면에 추가" ➕를 선택해요
3
오른쪽 위 "추가"를 누르면 끝!홈 화면에 생긴 🌱 아이콘으로 들어오면 알림도 켤 수 있어요.

안드로이드 · 3단계

1
크롬 오른쪽 위 ⋮ 메뉴를 눌러요
2
"앱 설치" 또는 "홈 화면에 추가"를 선택해요
3
"설치"를 누르면 끝!홈 화면에 생긴 🌱 아이콘으로 들어오면 알림도 켤 수 있어요.
